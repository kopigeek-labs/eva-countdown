# Changelog

## 0.1.0 — Prerelease (unpublished)

Initial public prerelease planned for Waveshare ESP32-S3-RLCD-4.2.

- Five-minute countdown with pause/resume, reset and restart after expiry.
- True LCD NGE digits, Japanese power panels, and monochrome final-minute warning.
- Native ESP-IDF application using synchronous SPI and no network services.
- Host renderer, reproducible font assets and previews, and focused logic checks.
- Build/flash documentation, third-party license notices, and local firmware packaging.
